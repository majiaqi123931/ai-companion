# LangChain → RAG 学习路线（2026.10 启动）

> 目标：12 月前把 AI 伴侣升级为"课程知识库 RAG 应用"——回答能带引用来源。
> 本目录记录每周学习笔记，代码练手进 `src/`，用 commit 记录进度。

## 阶段 1（第 1–2 周）：基础补齐

- 复习 Python 虚拟环境与 pip（AI 伴侣项目已经用过 OpenAI SDK，这块有底子）
- LangChain 核心概念：Model I/O（Prompt 模板 / Output Parser）、LCEL Chain 写法
- 产出：`notes/01.md` 笔记 + 一个最小 Chain 练手脚本

## 阶段 2（第 3–4 周）：RAG 原理与最小实现

- 流程：文档加载 → 切块 → Embedding → 向量库（先用 FAISS/Chroma 本地方案）→ 检索 → 生成
- 产出：能对一份 PDF 做问答的命令行 demo

## 阶段 3（第 5–6 周）：AI 伴侣 RAG 化改造

- 接入课程资料做知识库；回答附引用来源；Streamlit 界面展示"来源"区块
- 产出：可访问的部署链接 + `v2.0` 标签

## 记录方式

- 每周至少一篇笔记（踩坑也要记），推到本仓库，commit 就是学习痕迹
